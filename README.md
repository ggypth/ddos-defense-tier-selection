## 防御峰值怎么定档

服务商给出的经验口径是这样的：30G 保底对应个人博客、小型论坛、刚起步的私服；60G 到 100G 对应有一定用户量的游戏服、跨境电商后台；100G 到 300G 以上对应金融、支付、大型游戏、直播平台。这套划分来自恒创科技的产品文，是服务商的经验建议，不是行业标准，方向和实际遭遇的攻击规模大致对得上。

防御峰值直接决定价格。恒创香港高防云服务器 30G 月付 1466 元，60G 3973 元，100G 8001 元，CPU、内存、硬盘三档完全一样，只有防御在变，最高档是最低档的五倍多。「先买大的以防万一」在这个品类里是最贵的选法。

雨云的定价逻辑不太一样。宿迁 1核1G 只要 18 元/月，标称 150G 防御，防御能力摊在节点上而非单独计价。这种模式的限制是共享，实际能扛多少取决于当时节点的整体负载和攻击规模，不是每台机器独占 150G。

顺便说一个看宣传数字的方法。乐道主机的页面标题写「可抗 1T DDOS」「防御可至 1000G」，自家套餐表里最高只列到 200Gbps；ZoroCloud 的标题写「CERA 1200G DDoS 高防」，五个套餐的参数全是 50G DDoS Protection。标题里的数字通常是上游机房整体的清洗能力，套餐参数才是你实际买到的那一份，下单看后者。

## 保底防御和弹性防御的差价买的是什么

买高防 IP 时会看到两个数字。保底是你买的固定值，弹性是攻击超过保底后额外启用的兜底，通常按次数或者按 G 计费。

恒创香港高防 IP 的两个档位能看清差价买的是什么。30G 保底、0 弹性、2M CN2 带宽，1610 元/月；40G 保底、50G 弹性（1 次）、5M CN2，2377 元/月。多出来的 767 元里，10G 保底、50G 一次性弹性、3M 带宽三样都在里面。

只买保底、不买弹性，攻击超过保底时的处理就是封 IP 等人来升级。买弹性相当于预留了一次扩容额度，但「1 次」就是一次，打完还得再买。

## 超阈值之后会发生什么

四家服务商的处理方式可以并列看。

阿里云国际的免费基础防护，有代理商撰写的实操文章给出的口径是：攻击超过 5G 阈值，IP 进入黑洞，封禁 30 分钟到 2.5 小时，期间只能换 EIP 临时救站。这个数字没有在阿里云官方文档里找到对应条目，当参考看。

腾讯云在官方文档里写明，如果攻击影响到高防清洗中心的基础设施，腾讯云保留压制流量的权利，可能对业务限速甚至封堵。处置前会通过站内信、邮件、短信通知，可以自助解封或申请提前解封。

恒创的规则是攻击超过阈值且影响机房整体网络时，系统自动封停 IP，攻击停止后自动解封。要提前恢复就联系客服升级防护，官方说新防护秒级生效，不用换硬件。

雨云宁波节点在官方论坛公告里的说法是，攻击超过防御峰值，第一次黑洞最短 10 分钟。

四种处理方式有个共同点。超阈值不等于服务商替你把攻击扛下来，业务会中断一段时间，区别只在中断多久、恢复要不要人工介入。

## 只买流量清洗防不住 CC

腾讯云的官方文档把这条边界写得很清楚。云上资源（CVM、CLB、EIP、WAF、LH）只支持 L3/4 DDoS 防护，不支持 L7（CC）防护。EdgeOne 的域名同时支持 L3/4 和 L7，四层代理实例和代播网段只支持 L3/4。

这条对游戏服和支付站最要命。UDP Flood、SYN Flood 属于 L3/4，流量清洗能挡。CC 攻击走应用层，模拟正常请求打你的动态页面和登录接口，流量看着不大，服务器的 CPU 和数据库连接数先满。只买了流量清洗，CC 照样打穿。

腾讯云文档里还有两个数字值得记住。免费的标准防护最高不超过 2 Gbps 的 L3/4 能力；EdgeOne 场景默认只对超过 100Mbps 的攻击流量做自动化清洗。低于这个门槛的持续小流量骚扰，平台默认不管。

买之前问一句「这个套餐的防护覆盖到哪一层」，比盯着防御峰值数字有用。

## 买了高防还要做的三步

阿里云国际那篇实操文章里的流程，去掉厂商特有的部分，通用的有三步。

第一步，DNS 切到高防。网站业务把 A 记录或 CNAME 指向高防分配的 CNAME，APP 直连的把 A 记录指向高防独立 IP，DNS TTL 改成 10 分钟加速全网生效。

第二步，回源侧收敛。安全组只放行高防官方的回源 IP 段，屏蔽全网直接访问源站的业务端口。这一步不做，源站真实 IP 等于没藏，攻击者绕过高防直接打你的服务器，前面花的钱全部白费。这是整条链路上最容易省略、后果最严重的一步。

第三步，策略侧加固。CC 频率控制、单 IP 访问限流、IP 黑名单、区域封禁逐项配上，四层业务再开报文校验和虚假源 IP 过滤。免费版能做的有限，把 AI 智能防护设成正常、开单 IP 限速，也能缓解一部分 CC。

## 常见问题

**30G 防御能扛住多少攻击？**
30G 指每秒 30Gbps 的流量清洗能力。实际能扛多少取决于攻击类型和线路。腾讯云文档提到一个细节，中国大陆境内的防护容量按运营商线路分别部署，攻击集中在单一运营商线路时，该线路实际可防护规模可能低于标称值。30G 保底不等于任何类型的 30G 攻击都能扛满。

**被打了会自动升级吗？**
多数服务商不会自动升。恒创的规则是自动封 IP、攻击停止后解封，要升级得联系客服；带「弹性（1 次）」的档位属于预留一次扩容额度，不是无限自动升。

**高防能防 CC 吗？**
看产品覆盖到哪一层。腾讯云云上资源只支持 L3/4，不支持 L7 CC，只有 EdgeOne 域名支持。雨云各套餐的 L7 能力资料里没有明确标注，买之前问客服确认。

**换了高防原来的 IP 还能用吗？**
接入高防后，对外解析的是高防 CNAME 或高防 IP。源站原 IP 还在，但要通过安全组把公网直连业务端口关掉，否则等于没接高防。

**月付还是年付？**
不确定长期用就先月付，配首月 5 折试一个月；确定长期用再年付锁 7 折。两者的差额在雨云这里接近三成，用满一年就值得锁。
